## 这是什么

把书里的大观园做成一个可以漫游的网页：

- 首页是一张大观园平面图，十一个红点对应十一处院落
- 点任一处进去，可拖动环视，四层景深有前后
- 右下「太虚」进入判词，十六页，左图右文
- 底部「往哪儿走」可以在这园子里走到别处
