# 大观园 · 水墨卧游

把《红楼梦》里的大观园做成一个可以走进去的网页。

## 怎么看

打开 `index.html` 即可，不需要联网、不需要安装任何东西。

- 首页是一张大观园平面图，十一个红点对应十一处院落
- 点任一处进入，可拖动环视
- 右下「太虚」进入判词，十六页，左图右文
- 左上「園」印连点五下，是作者自己的问题记录面板

## 内容

- 十一处院落：沁芳亭、潇湘馆、怡红院、蘅芜苑、秋爽斋、稻香村、栊翠庵、紫菱洲、暖香坞、藕香榭、省亲别墅
- 太虚幻境：正册十二、副册一、又副册二
- 人物档案、逐回精读（一百二十回）、全文检索

## 说明

- 插图由 AI 生成，是水墨意象，不是考据复原
- 原文底本为脂评汇校本（前八十回）与程本（后四十回），与课本可能有个别字句差异
- 纯静态单文件，无框架、无服务器、不收集任何数据
