# 大观园 · 水墨卧游

### 👉 网址：https://liu-99811.github.io/daguan-yuan/

一座能走进去的《红楼梦》。纯静态单文件，无框架、无后端、不联网。

> 打开要等十几秒（13 MB 全部下载完才显示），耐心等一下。

---

## 这是什么

把书里的大观园做成可以漫游的网页：

- 首页是一张大观园平面图，十一个红点对应十一处院落
- 点任一处进去，拖动环视，四层景深有前后
- 右下「太虚」进入判词，十六页，左图右文
- 底部「往哪儿走」可以在园子里走到别处
- 「典 · 知识」可按回、按人、按物检索原文

十一处院落：沁芳亭、潇湘馆、怡红院、蘅芜苑、秋爽斋、稻香村、栊翠庵、紫菱洲、暖香坞、藕香榭、省亲别墅

## 仓库结构

```
├── src/                 源码
│   ├── index.html       页面骨架与样式
│   ├── app.js           主逻辑（院落、漫游、太虚、检索……）
│   ├── knowledge.js     知识库数据
│   └── feedback.js      问题记录（作者自用）
├── assets/              198 张插图 + 全文数据
├── build.py             打包脚本
├── dist/index.html      构建产物（网站用的就是它）
└── docs/                改动指南
```

**源码里图片写的是 `assets/xxx.jpg`，运行时才编码成 base64 并内联进单文件。**

---

## 怎么构建

```bash
python3 build.py
```

输出 `dist/index.html`（约 13 MB），双击就能打开，断网可用。

只依赖 Python 3 标准库，不需要 pip install。
