## 四、迁移时的几条硬规矩

**1. 动画重的块，不要重写成 React 状态驱动。**

`太虚幻境翻书`（#6）、`书页翻动`、`还泪`（canvas）、`园中路径`（#25）这类，靠 `requestAnimationFrame` + 精确时序。改成 React 后代码量翻倍、手感反而差。

**做法**：React 只做容器（决定何时挂载），内部保留原生命令式代码，用 `useEffect` 挂上去、卸载时清理。

```tsx
useEffect(() => {
  const cleanup = mountPanciBook(elRef.current)
  return cleanup
}, [])
```

**2. 一个模块迁完，把旧块从 `app.js` 删掉。**

不要两边都改，否则一定分叉。删之前确认新版能跑。

**3. 图片路径统一用相对路径 `assets/xxx`。**

新版 `vite.config.ts` 里 `base: './'`，相对路径在 GitHub Pages 子目录下也不会 404。

**4. 每迁一块，跑一次 `pnpm typecheck` 和 `pnpm build`。**

数据一多，类型错误会连锁。
